# AI Evaluation Metrics Definition

## Status

Draft

## Overview

Metrics are quantitative measurements used to evaluate the performance, reliability, safety, and cost effectiveness of AI systems.

The AI Evaluation Platform provides standardized metrics for:

- Traditional ML models
- Large Language Models
- Retrieval Augmented Generation systems
- AI Agents

# 1. Accuracy

## Definition

Accuracy measures how many predictions or responses are correct compared to the total number of evaluations.

Formula:

```
Accuracy = Correct Predictions / Total Predictions
```

Example:

```
Total Questions: 100

Correct Answers: 95


Accuracy:

95 / 100 = 95%

```

## Usage

Best suited for:

- Classification
- Structured outputs
- Exact answer tasks

---

# 2. Precision

## Definition

Precision measures how many predicted positive results are actually correct.

Formula:

```
Precision = True Positive / (True Positive + False Positive)

```

Example:

AI classifier detects spam emails.

```
Detected Spam:

100


Actually Spam:

90


Precision:

90%

```

## Usage

Important when false positives are expensive.

Examples:

- Fraud detection
- Medical diagnosis

---

# 3. Recall

## Definition

Recall measures how many actual positive cases were successfully identified.

Formula:

```
Recall = True Positive / (True Positive + False Negative)

```

Example:

```
Actual Spam Emails:

100


Detected:

95


Recall:

95%

```

## Usage

Important when missing cases is costly.

Examples:

- Security detection
- Disease detection

---

# 4. F1 Score

## Definition

F1 combines precision and recall into a single metric.

Formula:

```
F1 = 2 * (Precision * Recall)
     -------------------------
     Precision + Recall

```

Example:

```
Precision = 0.90

Recall = 0.80


F1 Score = 0.85

```

## Usage

Used when balancing false positives and false negatives.

---

# 5. Relevance Score

## Definition

Measures whether the AI response directly answers the user question.

Example:

Question:

```
How to deploy Docker?

```

Response:

```
Docker is a container platform.

```

Result:

```
High relevance

```

---

# 6. Faithfulness Score

## Definition

Measures whether the generated answer is supported by the provided context.

Especially important for RAG systems.

Example:

Context:

```
The company was founded in 2015.

```

Response:

```
The company was founded in 2010.

```

Result:

```
Low faithfulness

```

---

# 7. Hallucination Score

## Definition

Measures unsupported or fabricated information generated by AI.

Example:

AI creates:

```
Fake references

Incorrect facts

Invented data

```

Lower hallucination score indicates better reliability.

---

# 8. Completeness Score

## Definition

Measures whether the response covers all required information.

Example:

Expected:

```
Installation

Configuration

Deployment

```

Generated:

```
Only Installation

```

Result:

Low completeness.

---

# 9. Safety Score

## Definition

Measures whether AI responses comply with safety requirements.

Checks:

- Harmful content
- Bias
- Privacy violations
- Unsafe instructions

Example:

```
Safety Score: 0.98

```

---

# 10. Latency Metrics

AI applications require performance measurement.

## Time To First Token (TTFT)

Time until first response token arrives.

```
Request

 |

First Token

```

Important for streaming applications.

---

## Total Response Latency

Total generation time.

Formula:

```
End Time - Start Time

```

---

# 11. Throughput

Measures system capacity.

Formula:

```
Requests Processed / Time

```

Example:

```
500 requests/minute

```

---

# 12. Token Usage

Measures model consumption.

Tracks:

- Input tokens
- Output tokens
- Total tokens

Example:

```json
{
  "input_tokens": 500,
  "output_tokens": 300,
  "total": 800
}
```

---

# 13. Cost Metric

Measures financial impact.

Formula:

```
Cost = Token Usage × Provider Price

```

Example:

```
100000 tokens

=

$5.00

```

---
